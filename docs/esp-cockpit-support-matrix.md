# ESP-Cockpit 组件支持矩阵

本矩阵记录经验证的具体产品配置及其组件支持等级。需求文档中的 target 清单仅定义候选验收等级，不代表所有模组、板卡或构建配置均已验证。未在矩阵登记并附有证据的配置，不得从相同 SoC target 的其他结果推定支持。

每条记录至少应包含：

- 产品/硬件版本、模组/板卡、SoC target 与 revision。
- ESP-IDF 精确版本、网络接口/驱动、PSRAM 配置。
- TLS 后端、安全构建选项及其他影响安全或资源的生产构建配置。
- 组件/固件版本和 commit、已通过的构建/核心功能/性能等级。
- 验收日期、结果摘要及不可变发布附件中的完整证据链接。

安全、网络或资源关键配置变更时，责任方须重跑受影响的验收并更新记录。发布负责人依据本矩阵执行等级门禁；缺少适用验收或证据时，不得按该等级发布。
