# OTA 支持矩阵

本矩阵按产品、硬件版本、ESP-IDF target/revision 和生产构建配置记录 OTA 支持状态。只有完成对应配置的适用硬件验收，才能标记为“生产 OTA 支持”；其他配置不得从同一 target 的测试结果推定支持。

| 产品 / 硬件版本 | IDF target / SoC revision | 生产构建配置 | OTA 支持等级 | 最近验证版本 | 验收证据 |
|---|---|---|---|---|---|

支持等级定义及验收要求见[组件需求文档](./esp-cockpit-requirements.md)。完整硬件报告和测试日志作为相应正式发布的附件保存，并在“验收证据”列链接；矩阵只保留便于查阅和审核的摘要，避免在源码仓库保存大体积日志。

验收证据至少覆盖有效签名映像升级并健康启动、无效签名或产品/硬件不匹配映像被拒绝、失败回滚或掉电恢复，以及该配置的映像大小和上传超时边界。正式发布时，每个已支持生产配置还须验证该发布版本升级成功并正常启动。
